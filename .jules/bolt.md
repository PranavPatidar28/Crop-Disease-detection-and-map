## 2024-08-03 - Memoize map marker components to prevent O(N) re-render waterfalls
**Learning:** In React Native apps using `react-native-maps`, rendering many markers (or custom layers) from an array dynamically (like `array.map()`) can cause a massive performance bottleneck. Because components like `MapMarker`, `OutbreakZoneLayer`, `MapCluster`, and `TrackingMarker` represent individual items in a larger, changing list (e.g. visible region changes, filter updates, or pan/zoom), re-rendering the parent container will force all these list items to re-render. Since marker creation and layout recalculation is very expensive, this results in O(N) re-render waterfalls that degrade map performance significantly.
**Action:** When working with non-virtualized lists (like rendering `Marker` components over a map), always wrap the individual list item components in `React.memo()` using the named inner function pattern (e.g., `const Component = memo(ComponentImpl)`).
